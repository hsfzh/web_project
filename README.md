# 감정의 흔적

## 작품 질문

사람은 자신의 감정을 표현하고 마주하는 과정을 통해 어떻게 마음의 변화를 경험할 수 있을까?

## 작품 소개

《감정의 흔적》은 관객이 지금 느끼는 감정을 고르고, 그 감정을 글로 적어 화면의 빛으로 마주하는 인터랙티브 웹 작업이다. 감정은 글의 해석을 통해 서로 다른 색과 움직임을 가진 빛으로 나타난다. 관객은 빛이 화면에 머무는 모습을 살펴보고, 원할 때 ‘빛을 보내기’를 눌러 빛을 중앙으로 모아 보낸다.

빛이 모이고 사라지는 동안 화면은 서서히 밝아진다. 이 장면은 감정이 해결되었음을 뜻하거나 특정한 변화를 강요하지 않는다. 감정을 글로 꺼내어 바라보고, 잠시 놓아주는 경험을 시각적으로 표현한다. 화면이 잠잠해진 뒤에는 이야기를 남겨준 데 대한 감사 문구와 ‘다시 적기’ 버튼을 보여주어, 관객이 원하면 다시 시작할 수 있게 한다.

## 관객 경험

1. 지금 느끼는 감정을 선택하고, 그 감정에 어울리는 색을 고른다.
2. 마음에 걸리는 일을 자유롭게 적는다. 입력한 글은 감정을 빛으로 표현하는 데 사용된다.
3. 빛의 색과 움직임을 바라보며 감정의 흔적을 살펴본다.
4. 준비가 되면 ‘빛을 보내기’를 눌러 빛이 모여 사라지는 과정을 지켜본다.
5. 원한다면 ‘다시 적기’를 눌러 새로운 감정을 표현한다.

## 구현과 동작

작업물은 GitHub Pages에서 실행되는 웹 페이지이다. 관객은 감정을 선택하고 색을 지정한 뒤 글을 입력한다. 별도의 AI 모델이나 외부 API는 사용하지 않는다. 브라우저 안에서 입력 글자 수와 작성 시간, 작성 중 멈춘 시간, 지운 횟수를 바탕으로 비중을 계산한다. 선택한 감정은 중심 감정으로 유지하고, 다른 감정의 종류와 일부 비중은 무작위로 정한다. 따라서 글의 의미나 문장 내용 자체를 읽어 감정을 판정하지는 않는다.

계산된 감정별 비중에 따라 화면에 빛을 만들고, 각 빛은 감정의 색과 움직임으로 표현된다. 마무리 과정에서는 선택한 중심 감정의 빛이 중앙으로 모여 터지고, 나머지 빛은 각자의 방향으로 화면 밖으로 나간다. 빛의 소멸에 맞춰 배경도 어두운 색에서 흰색으로 천천히 변한다.

## 질문과 의도

감정을 말이나 글로 표현하면 막연했던 마음을 구체적으로 바라볼 수 있다. 이 작업은 감정을 선택하고 글로 적는 행위를 통해 관객이 자신의 상태를 잠시 살펴보도록 제안한다. 글이 빛으로 바뀌는 장면은 내면의 감정을 바깥에 드러내어 관찰하는 순간을 나타낸다.

빛을 보내는 과정은 감정을 없애거나 완전히 해결하는 결말이 아니다. 빛은 천천히 모이고 화면은 밝아지지만, 그 변화가 관객의 실제 감정까지 바꾸었다고 단정하지 않는다. 작품은 감정을 마주하고 잠시 놓아보는 하나의 경험을 제공하며, 다시 적기를 통해 그 과정이 언제든 이어질 수 있도록 열어 둔다.

## AI 활용 과정 · AI USE NOTE

- 감정 비중은 브라우저에서 작성 속도, 멈춘 시간, 지운 횟수를 조합해 계산한다. 선택한 중심 감정 이외의 감정 구성과 가중치 배분에는 무작위 요소가 포함된다.
- Codex는 제작 과정에서 코드 작성과 수정, 오류 점검을 돕는 도구로 활용했다.
- 화면에 나타나는 감정은 글의 의미를 분석한 결과나 객관적인 진단이 아니라, 관객의 선택과 작성 행동을 작품의 규칙으로 시각화한 것이다.

## 실패와 배운 점

처음에는 기쁨, 슬픔, 분노처럼 감정을 미리 정해두고 점수만 받도록 했다. 하지만 이 방식으로는 문장에 함께 드러나는 여러 감정과 관객마다 다른 표현을 담기 어려웠다. 감정 이름을 자유롭게 생성하도록 바꾸자 문장에 어울리는 다양한 결과를 표현할 수 있었지만, 색이 지나치게 옅거나 감정과 잘 맞지 않는 경우도 있었다. 모델이 색을 고르는 기준을 더 구체적으로 안내할 필요가 있음을 배웠다.

AI 응답이 예상한 JSON 구조와 다를 수 있어, 결과를 파싱하고 감정 이름, HEX 색상, 비중을 확인하는 처리가 필요했다. 또한 감정을 표현하는 단계와 빛을 보내는 단계를 나누고, 빛의 움직임과 배경의 밝아짐을 함께 조정하면서 마무리 장면의 속도와 흐름이 관객 경험에 큰 영향을 준다는 점을 확인했다. 화면의 변화는 감정을 단정적으로 해결하는 효과가 아니라, 관객이 자신의 감정을 바라보도록 돕는 표현으로 설계하고자 했다.
